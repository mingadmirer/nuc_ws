# 崇武探幽 — 全流程说明 (v3)

## 1. 系统拓扑

```
RDK X5 (192.168.127.10) ── 网线 ──► NUC 6i7kyk (192.168.127.1)
    │                                     │
    │ /detections (DetectionArray)        │ r2_mission 节点
    │ ~15Hz                               │ 状态机 + 批次伺服
    │                                     │
    ▼                                     ▼ USB CDC (by-id)
  Aurora 930 + YOLOv5 BPU               STM32 下位机
  chrony NTP Server                     chrony NTP Client
```

**时间同步**：RDK 为 NTP Server，NUC 为 Client，有线直连误差 < 0.5ms。

## 2. 通信协议

### RDK → NUC：`/detections` (ROS 2 Topic)

`detection_interfaces/msg/DetectionArray`，每帧含 `detections[]` (name, bbox, depth_mm, timestamp)。

### NUC → STM32：USB CDC ASCII 协议（115200 baud）

| 格式 | 示例 | 含义 |
|------|------|------|
| `Mfwrd01250` | M + fwrd + 速 | 前进 |
| `Mbwrd01250` | M + bwrd + 速 | 后退 |
| `Mrtrl01250` | M + rtrl + 速 | 右移 |
| `Mltrl01250` | M + ltrl + 速 | 左移 |
| `Mrtrn02000` | M + rtrn + 速 | 右旋 |
| `Mltrn02000` | M + ltrn + 速 | 左旋 |
| `Mstop00000` | M + stop | 停止 |
| `Mfing55555` | 夹紧 | `Mfing44444` 松开 |
| `Mfwrs00120` | M + fwrs + 角 | 腕部角度 (0~220) |

10 字节定长 ASCII，STM32 维持最后收到的速度直到新指令。

## 3. 全流程

```
═══════════════════════════════════════════════════════════

启动            握手机制 + 腕部复位 Mfwrs00120

1. INIT         等待 2s

2. ALIGN_RACK   右移 2000 × 2.0s → Mstop

3. APPROACH_SPEAR 深度伺服 → 650mm
   收连续30帧 → 一致性筛选 (≥20帧, ±20%)
   → 锁定目标深度 → 移动时间 = |err| / 250mm/s
   → 右移2000(或左移) × 计算时间 → Mstop → 循环
   到达: |err| < 50mm → ALIGN_LATERAL
   超时: 15s → 强推

4. ALIGN_LATERAL 横向伺服
   收连续30帧 → 一致性筛选 → 锁定目标像素
   → 横向偏差 = -pixel_off × depth / fx (fx=415.9)
   → 移动时间 = |err| / 300mm/s
   → FORWARD/BACKWARD 2000 × 计算时间 → Mstop → 循环
   到达: |err| < 15mm → FINAL_APPROACH
   超时: 10s → 强推
   目标偏置: cx=310 (可调，使目标偏左/右)

5. FINAL_APPROACH
   右移 2000 × 0.8s → Mstop
   → 腕部 100 → 右移 800 × 1.0s → Mstop

6. GRIP_LIFT
   夹紧 Mfing55555 → 等 0.5s → 腕部 Mfwrs00210 → 等 0.5s

7. RETREAT_ROTATE
   左移 2000 × 5.0s → 右旋 2000 × 1.2s → Mstop

8. COMPLETE
   等 1s → 松爪 Mfing44444

═══════════════════════════════════════════════════════════
```

## 4. 伺服策略

两段伺服（深度 + 横向）均使用**距离→时间**计算，不再用 PD：

```
误差 → 移动时间 = |误差|/速度 → 固定2000发一次 → 定时停止 → 重新收集验证
```

深度：250mm/s，横向：300mm/s。每轮移动后收集 30 帧重新评估，保证收敛精度。

## 5. STM32 握手机制

启动时轮询串口，发送 `Mstop00000`，等待 STM32 回复 `Car stopped`，确认固件就绪后才继续。

## 6. 可调参数速查

### 时序
| 参数 | 默认值 |
|------|--------|
| startup_delay_s | 2.0 |
| release_delay_s | 1.0 |

### 开环运动
| 参数 | 默认值 |
|------|--------|
| initial_right_speed | 2000 |
| initial_right_time_s | 2.0 |
| translate_left_speed | 2000 |
| translate_left_time_s | 5.0 |
| rotate_right_speed | 2000 |
| rotate_right_time_s | 1.2 |

### 深度伺服
| 参数 | 默认值 |
|------|--------|
| target_depth_mm | 650.0 |
| depth_threshold_mm | 50.0 |

### 横向伺服
| 参数 | 默认值 |
|------|--------|
| fx | 415.9 |
| cx | 310.0 |
| lateral_threshold_mm | 15.0 |
| lateral_timeout_s | 10.0 |

### 盲走近端
| 参数 | 默认值 |
|------|--------|
| final_approach_speed | 2000 |
| final_approach_time_s | 0.8 |

### 夹爪/腕部
| 参数 | 默认值 |
|------|--------|
| grip_delay_s | 0.5 |
| wrist_delay_s | 0.5 |
| 腕部硬编码值 | 启动120, 盲走后100, 抬起210 |

### 伺服批次
| 参数 | 默认值 |
|------|--------|
| det_window_size | 30 |
| det_min_inliers | 20 |
| det_consistency_pct | 0.2 |

### 串口
| 参数 | 默认值 |
|------|--------|
| serial_device | /dev/serial/by-id/usb-STMicroelectronics_STM32_Virtual_ComPort_... |
| baudrate | 115200 |

## 7. 编译与运行

```bash
cd ~/nuc_ws
source /opt/ros/humble/setup.bash
colcon build
source ~/nuc_ws/install/setup.bash
ros2 launch r2_mission bringup.launch.py
```

改 YAML 参数需要 `colcon build` 同步到 install。改 C++ 源码同理。
